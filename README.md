# Servicios Web · Sebastián Araque

Página de presentación de servicios de desarrollo web (restaurantes, tiendas, tiendas virtuales y agendamiento de citas) con contacto directo por WhatsApp.

Es un único archivo `index.html`, sin dependencias. Para publicarla, activa **GitHub Pages** (Settings → Pages → rama `main`, carpeta `/`).

Para cambiar el número de WhatsApp, busca `573245614442` en `index.html` y reemplázalo.
